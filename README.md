# 音频可视化 MV 生成器

因为在制作ニコカラ时可能出现找不到合适 MV 的情况，因此制作了这个脚本用于一键生成简单的音频可视化 MV。

脚本会将封面图片和音频合成为 MP4 视频，内容包含旋转封面、频谱图、简单背景和粒子等，背景素材为 AI 生成，附带一键启动的bat文件。

## 运行环境

- Windows，安装带 Tkinter 的 Python 3.10 或更新版本。
- Python 依赖：NumPy、OpenCV、Pillow。
- FFmpeg 和 FFprobe。

运行 Python 安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## 使用步骤

1. 双击 `start_vinyl_mv.bat`。
2. 分别选择封面图片、音频和输出 MP4 路径。。
3. 按需设置尺寸、FPS 和唱片封面 RPM。默认参数为 **1920 × 1080、30 FPS、2.5 RPM**。
4. 在颜色页设置背景灯光与频谱颜色。
5. 先点击“预览”检查效果：生成最多 8 秒、宽度 960 的预览视频。
6. 点击“生成视频”导出完整音频长度的视频。完成弹窗中可打开输出文件夹。

图片会裁切为圆形封面。生成视频需要一段时间。
